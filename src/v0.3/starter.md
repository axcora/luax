# LUAX v0.3 Legacy Docs

This is the **legacy v0.3 documentation** - kept for historical reference.

## What was v0.3?

v0.3 was the first minimal working version of LUAX. No versioned folders, no router, just pure `src/*.md` -> `dist/*.html`.

If you are looking for versioned docs support (`/v0.3/about/`), you are actually using v5.2 feature that FIXES v0.3 folder handling!
