# Deploying LUAX Sites

Deploy your LUAX site to any hosting platform.

## GitHub Pages

Push to GitHub and use GitHub Actions.

## Netlify

Create netlify.toml with build command.

## Vercel

Use vercel.json for configuration.

## Manual Deploy CPANEL / VPS

Upload the dist folder to your server.

Simple and easy.
