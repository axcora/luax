# Why Lua is Great for Static Sites

Lua is a simple programming language with many advantages.

## Lightweight

Lua has a small footprint. No heavy dependencies or complex toolchains.

## Fast

Lua executes code quickly. LUAX builds your site in milliseconds.

## Portable

Lua runs everywhere - Windows, Linux, and macOS.

## Simple Syntax

Lua is easy to learn and read.

These qualities make Lua perfect for static site generators.
