## Writing Content with Markdown and YAML

LUAX uses Markdown for content and YAML for metadata.

## Create a Post

Add a new .md file in `src/posts/`

## Frontmatter Example
```
---
title: My Post
date: 2024-01-01
tags: lua, tutorial
author: LUAX Team
---
```
## Writing Content

Just write Markdown below the frontmatter.

## Headings

Use # for headings.
